# Algoritmos de ordenacao em Python

Implementacao na mao de bubble sort, selection sort e insertion sort, sem usar
`sorted()` nem `list.sort()`. Cada funcao devolve a lista ordenada e quantas
trocas fez, pra dar pra comparar os tres.

## O que pratiquei

- Os tres algoritmos classicos de ordenacao por comparacao
- Diferenca entre trocar elementos (bubble e selection) e deslocar elementos
  (insertion)
- Contar operacoes pra ter uma nocao de custo, alem de so olhar o resultado

## Como rodar

```
python main.py
```

Gera uma lista aleatoria de 15 numeros, ordena com os tres algoritmos e
mostra quantas trocas cada um fez.
